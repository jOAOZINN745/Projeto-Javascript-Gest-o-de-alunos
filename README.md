# Projeto-Javascript-Gest-o-de-alunos

O projeto de gestao de alunos é uma aplicação desenvolvida para cadastrar estudantes, calcular as médias dos alunos, automatizar e fazer o acompanhamento acadêmico e administrativo de estundantes.

# Tecnologias utilizadas

- **HTML5** : Para a estrutura da pagina e o formulário de cadastro.
- **CSS3**: Para a estilização visual da pagina.
- **JavaScript (ES6+)**:Validação dos dados, cálculo de média, Manipulação do dom e atualização dos resumos.
- **Git e GitHub**:Para controle de versão, branches e committ

# Funcionalidades

- Cadastro de estudantes com o nome completo, idade, turma, nota 1 e nota 2.
- Validação de campos obrigatórios, idade positiva e notas entre 0 e 10.
- Cálculo automático da média aritmética das duas notas e definção da situação do estudante (Aprovado ou Reprovado).
- Exibição dos estudantes em cartões visuais com cores distintas para alunos Aprovados e reprovados.
- Remoção individual de estudantes cadastrados, com atualização imediata da lista e do resumo.
- Limpeza do formulário e da mensagem de feedback ao clicar em **Limpeza formulario**.
- Painel de resumo com contadores de **Total de alunos**, **Aprovados** e **Reprovados**.
- **Desafio extra**: prevenção de cadastro duplicado verificando se já existe um aluno com o mesmo nome.

# Como executar

1. Faça o download do arquivo compactado (.zip) diretamente no repositório do GitHub.
2. Localize a pasta onde o arquivo foi salvo e extraia o seu conteúdo.
3. Abra o arquivo index.html utilizando qualquer navegador moderno de sua preferência (como Google Chrome ou Mozilla Firefox).

# Como usar a página

# 1. _Cadastrar um estudante_

1. Preencha **Nome completo**, **Idade**, **Turma**, **Nota 1** (0 a 10) e **Nota 2** (0 a 10).

2. Clique em **Cadastrar aluno**.

3. Se todos os dados forem válidos, o estudante aparecerá na seção **Estudantes cadastrados** e vai ter o registro com as informaçoes desse aluno e se não for valido o sistema ia te indicar oque falta para concluir o cadastro.
